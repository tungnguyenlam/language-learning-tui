# Agent Bootstrap

This file is intentionally small. Do not put backlog, chat transcripts, or implementation history here.

1. Read `docs/agent/start-here.md`.
2. Check `docs/backlog/active.md`.
3. Follow `docs/agent/continuity.md` for session pickup, notices, backlog updates, and handoff.
4. Read the nearest package README and subtree `AGENTS.md` for the files you will touch.
5. Inspect current code before editing.
6. **Continuous Documentation:** You MUST update `docs/backlog/active.md` and relevant continuity docs *continuously* as you complete tasks, change plans, or discover new context, not just at the end of the session.
7. Keep edits narrow, remove stale code, and update continuity docs when contracts or next steps change.
8. Run targeted tests first, then `./scripts/verify.sh` when feasible.

Durable notices belong in `docs/agent/notices/`.
Architecture decisions belong in `docs/decisions/`.
Backlog state belongs in `docs/backlog/`.
